\section{Projects}

\begin{jobshort}{AI Solutions Advisor}{\textit{React 19, TypeScript, FastAPI, Bedrock}}
Full stack chat application backed by an AI agent. Front-end in React 19 with TypeScript and Vite, featuring the conversation interface and a debug panel for tool calls; back-end in Python with FastAPI and Pydantic validation, exposing the \texttt{/api/chat} and \texttt{/health} endpoints. The Strands agent running on Amazon Bedrock is equipped with custom tools for calculation, date/time and catalogue lookup. Tested with Vitest and Testing Library on the front-end and pytest with Hypothesis on the back-end.
\end{jobshort}

\begin{jobshort}{PDPoint system modernisation}{\textit{ASP.NET Core 8, C\#, PostgreSQL, Docker}}
Migration of an ASP.NET MVC application from .NET Framework to ASP.NET Core 8: over 20 controllers and 180 Razor views rewritten, data layer switched to Npgsql (PostgreSQL), structured logging with Serilog, object mapping with AutoMapper, PDF generation with PuppeteerSharp and containerisation for deployment through Azure Pipelines.
\end{jobshort}

\begin{jobshort}{Number Portability and Facade APIs}{\textit{Node.js, TypeScript, Express, Prisma}}
Modernisation of legacy APIs for a telecommunications carrier. The Facade API was rewritten in Node.js 22 with TypeScript, Express and Prisma, organised in Clean Architecture (entities, use cases, handlers), with resilient integrations using retry and circuit breaker, Vitest test coverage, secrets and storage on Google Cloud and automated deployment. The Portability API was modernised in .NET with background jobs, webhooks and execution on Kubernetes.
\end{jobshort}

\begin{jobshort}{Multi-tenant conversational agent platform}{\textit{AWS CDK, Python, Bedrock}}
WhatsApp chatbot with complete per-client isolation. Webhooks arrive through API Gateway and trigger an ACK Lambda that consolidates message fragments in a DynamoDB buffer and enqueues them in SQS with a delay; the invocation Lambda dynamically retrieves the client configuration and answers through Bedrock using a dedicated Knowledge Base. EventBridge keeps the vector store in sync, and every transaction records conversation tracing and token consumption for cost allocation. Infrastructure entirely in AWS CDK (Python), deployed via GitHub Actions.
\end{jobshort}

\begin{jobshort}{Intelligent document validation and extraction}{\textit{Python, Lambda, Textract, Terraform}}
Serverless pipeline that validates authenticity and extracts structured fields from 12 groups of Brazilian documents, combining Rekognition, Textract and Bedrock. Modular architecture with dedicated validators and extractors per document type following the Template Method pattern, a REST API documented in OpenAPI, Lambda Layers for dependencies and infrastructure provisioned with Terraform.
\end{jobshort}
